# Portfolio Website

A modern, responsive portfolio built with React and TypeScript.

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Tech Stack

- React + TypeScript + Vite
- Tailwind CSS
- Framer Motion
- Radix UI

## Project Structure

```
src/
├── components/       # UI components
├── pages/           # Page views
├── hooks/           # Custom hooks
├── lib/             # Utilities
└── index.css        # Styles

public/
└── imgs/            # Images
```

## Customization

Edit components in `src/components/` and `src/pages/` to update content. Replace images in `public/imgs/` with your own.
